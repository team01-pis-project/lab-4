## Описание проекта

В данной лабораторной работе проводится статический анализ Java-кода с помощью инструмента SpotBugs.

## Задания
**Задание 1** — Разработать программы по примерам из файла «FindBugs помогает узнать Java лучше.mhtml», проверить их через SpotBugs, описать найденные проблемы и исправления.

**Задание 2** — Проверить проект library (с подключением jsr305-2.0.0.jar) с помощью SpotBugs, описать результаты.

**Задание 3** — Проверить библиотеку colt с помощью SpotBugs, описать наиболее критичные проблемы (если их больше десяти).
